Fitur Platform

Semua yang Anda Butuhkan tentang Tsunami

Informasi terintegrasi dan terpercaya dari sumber resmi pemerintah Indonesia

📊
Dashboard Statistik
Visualisasi data kejadian tsunami, korban, dan wilayah terdampak dengan grafik interaktif.
🗺️
Peta Rawan Tsunami
Peta interaktif zona bahaya tsunami dan kejadian historis di seluruh wilayah Indonesia.
🗂️
Database Historis
Kumpulan data lengkap kejadian tsunami di Indonesia dengan detail magnitudo, korban, dan dampak.
📡
Monitoring BMKG
Pantau informasi gempa bumi terkini dari BMKG dan status potensi tsunami secara real-time.
🔍
Pencarian Korban
Cari dan laporkan orang hilang akibat tsunami. Pantau status pencarian secara resmi.
📚
Pusat Edukasi
Pelajari tsunami — pengertian, proses, tanda-tanda, dampak, dan panduan mitigasi lengkap.
🎮
Simulasi Mitigasi
Mini-game edukatif untuk menguji dan meningkatkan kesiapsiagaan Anda menghadapi tsunami.

Sumber Data

Data Resmi yang Terpercaya

Seluruh data pada platform ini bersumber dari lembaga resmi pemerintah Indonesia

🏛️
BMKG
Badan Meteorologi, Klimatologi, dan Geofisika. Sumber data gempa, peringatan dini tsunami, dan katalog historis.
bmkg.go.id ↗
🏛️
BNPB / InaRISK
Badan Nasional Penanggulangan Bencana. Sumber data peta bahaya dan risiko tsunami nasional.
bnpb.go.id ↗
🌐
NGDC/NOAA
National Geophysical Data Center/NOAA. Database tsunami global sebagai referensi data historis internasional.
ngdc.noaa.gov ↗
⚠️ Catatan Data: Data pada platform ini bersumber dari lembaga resmi. GELOMBANG AMAN tidak membuat prediksi tsunami, tidak menerbitkan peringatan mandiri, dan tidak mengarang data kejadian. Selalu pantau informasi resmi BMKG untuk status peringatan tsunami.
